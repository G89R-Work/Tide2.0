# Einstellungen

Stand 2026-11-11 · Teil des Gesamtkonzepts. „Deine Version" meint den alten Prototyp 3, „meine Beispielseite" die Beispielseite vom 10.11.

Die Einstellungen sind eine eigene Seite wie Postfach oder Arbeit, mit derselben Bedienung: Die Hauptseite zeigt das Grundlegende, die zweite Ebene führt zu den Abschnitten. Aufbau und Suche kommen aus deiner Version.

| --- | --- | --- |
| Allgemein | Konten und Kalender | Alle Konten an einem Ort, siehe unten |

Dein Abschnitt „Sprache und KI“ wird zu „Sprache und Schreiben“, solange Tide ohne KI läuft.

## Konten an einem Ort

Konten werden auf jedem Gerät nur hier hinzugefügt. Die Liste zeigt jedes Konto mit Farbpunkt und Zustand, die Reihenfolge ist ziehbar und gilt überall: Postfach, Kalender, Filter. Eine abgelaufene Anmeldung zeigt hier „Neu verbinden“.

Ein Klick auf ein Konto öffnet, was dieses Konto tut:

| Einstellung | Auswahl |
| --- | --- |
| Mail | an oder aus |
| Kalender | an oder aus, je Kalender des Kontos einzeln |
| Name und Farbe | frei |
| Raum | Privat, Arbeit oder ein geteilter Raum |
| Signatur | eine der angelegten Signaturen |
| Standard-Absender | ja oder nein |
| Meldestufe | Sofort, zur Flut, still |
| Zeitraum | Wie weit zurück Mails geladen werden |
| Trennen | Konto entfernen, mit Rückfrage |

Der Zustand „bewusst nicht verbunden“ aus deiner Version bleibt. Er hält sichtbar fest, dass ein Postfach absichtlich draußen bleibt.

## Alles ist einstellbar, ohne dass es teuer wird

Jede Einstellung ist eine Zeile in einer zentralen Liste: Name, Art, Standardwert, Abschnitt. Die Einstellungsseite, ihre Suche und „Auf Standard zurücksetzen“ entstehen daraus von allein. Eine neue Option kostet eine Zeile und keine neue Oberfläche.

Alle Einstellungen gelten je Nutzer. Anordnungen gelten zusätzlich je Geräteart.
