# To-dos

Stand 2026-11-11 · Teil des Gesamtkonzepts. „Deine Version" meint den alten Prototyp 3, „meine Beispielseite" die Beispielseite vom 10.11.

To-dos sind das, was in deiner Version Erinnerungen heißt. Der Name kommt von meiner Seite, die Funktionen kommen von deiner.

## Aufbau

- **Zweite Ebene:** die Herkunft als Ordner, wie bei dir: Alle, Eigene, Mails, Rückrufe, Arbeit, Rechnungen, dazu geteilte Listen und das Archiv. Die Reihenfolge ist ziehbar.
- **Hauptkachel:** die Liste, gruppiert nach Fälligkeit: Überfällig, Heute, Diese Woche, Später, Irgendwann. Ziehen zwischen den Gruppen ändert nur die Frist.
- **Eingabezeile:** „heute“, „morgen“ oder „übermorgen“ im Text setzen die Frist gleich mit.

## Funktionen

| Funktion | Beschreibung |
| --- | --- |
| Suche | Ein Suchfeld über der Liste, Treffer werden markiert. Neu, von dir gewünscht |
| Archiv | Erledigtes wandert ins Archiv und wird nach 30 Tagen gelöscht. Die Frist ist einstellbar |
| Quelle | Jedes To-do aus einer Mail, einem Rückruf oder einer Rechnung verweist auf seine Quelle. Löschen entfernt nur das To-do, nie die Mail oder den Termin |
| Verknüpft erledigen | Wird das To-do erledigt, gilt die verknüpfte Mail oder der Rückruf gleich mit |
| Irgendwann-Wecker | Liegt etwas ohne Datum zu lange herum, kommt es nach vorne |
| Treibgut | Offene To-dos ohne Uhrzeit treiben in der Gezeitenkurve mit |
| Hartnäckig | Einzelne To-dos melden sich wiederholt, bis sie erledigt sind |
| Geteilt | Listen in einem geteilten Raum, mit Zuweisung |
| Automatisch angelegt | Tide legt To-dos aus Rechnungen und Fristen an, die Frist kommt aus der Mail |
