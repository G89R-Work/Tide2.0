# Notizen

Stand 2026-11-11 · Teil des Gesamtkonzepts. „Deine Version" meint den alten Prototyp 3, „meine Beispielseite" die Beispielseite vom 10.11.

Notizen sind Kacheln, die du groß ziehst, verschiebst und in Ordnern sammelst.

- **Zweite Ebene:** Ordner mit Unterordnern, wie im Postfach. Eine Notiz auf einen Ordner ziehen verschiebt sie.
- **Kacheln:** Jede Notiz zeigt Titel und Anfang. Langer Druck oder Rechtsklick öffnet das Anpassen: Größe, Platz, Farbe.
- **Suche und „Neue Notiz“** stehen nebeneinander über den Kacheln.
- **Lesen und Schreiben:** Ein Klick öffnet die Notiz im großen Fenster. Änderungen werden sofort gespeichert.
- **Format:** einfacher Text im Markdown-Format, verträglich mit Obsidian. Der Rohtext bleibt immer erhalten.
- **Sprechen:** Der Diktat-Knopf füllt eine Notiz, siehe Übergreifend.
- **Verknüpfen:** Eine Notiz kann an einem Termin, einer Mail oder einem Rezept hängen.
